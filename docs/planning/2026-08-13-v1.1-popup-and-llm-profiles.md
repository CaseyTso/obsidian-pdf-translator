# PDF Translator V1.1 — 弹窗与 LLM 配置档冻结规格

> 决策来源：2026-08-13 `/grill-with-docs`。本文件是 Kanban 实现与验收的产品规格；术语定义见根目录 `CONTEXT.md`。

## 目标

1. 修复翻译弹窗在多栏 Obsidian / 长译文场景中的宽高、定位和双重滚动问题。
2. LLM 设置页增加基于未保存草稿的真实连通性测试。
3. 增加可保存、切换、更新、重命名和删除的 LLM 配置档。
4. 复制成功后给出纯图标反馈。

## 1. 翻译弹窗

- 活动边界是当前 PDF 阅读区域，而不是整个 Obsidian 窗口；不得进入左右侧栏。
- 优先位于选区下方；下方不足则放上方；两边都不足时选择空间更大的一侧，压缩译文区，不遮挡选区。
- 默认可读宽度约 420px；PDF 区较窄时自适应缩小并保留边距。
- 最大高度约 PDF 阅读区域的 45%；短译文按内容高度，不强制撑满。
- 只有译文区可滚动；操作按钮固定可见；禁止 body/result 双层滚动。
- PDF 滚动或切页后，已打开弹窗保持屏幕原位置，不持续追踪原选区；新划词替换旧弹窗。
- 复制成功后 copy icon 临时变为 check icon，约 1.5 秒后恢复；不显示文字；连续复制重新计时。
- 保留现有 Esc、点外部、新划词关闭/替换行为和明暗主题变量。

## 2. 连通性测试

- Test 使用设置页当前配置草稿：Base URL、API key、model；不要求先保存。
- 发一次极短的真实 OpenAI-compatible `/chat/completions` 请求，以固定 `Hello` → 中文短翻译验证 URL/key/model/协议；不发送 PDF 文献内容。
- 成功条件是 2xx 且返回非空内容，不要求严格返回 `OK`。
- 设置页原位显示成功/失败、耗时、简短响应或映射后的 HTTP 错误。
- Test 不保存、不应用、不切换配置；结果不持久化。
- 保存配置档不强制 Test 成功。
- API key 不得出现在日志、UI 测试结果或错误文本中。

## 3. LLM 配置档

每个配置档保存：唯一名称、Base URL、API key、model、翻译提示词。目标语言是全局设置，不属于配置档。

### 生命周期

- 升级迁移：旧 Base URL/key/model 均完整时，自动建立并启用「默认配置」；不完整时只保留草稿，不建无效配置档。迁移幂等。
- 配置档按最近使用排序，当前配置档置顶。
- 新建：名称 trim 后非空且唯一；保存成功后立即启用。
- 更新：按钮明确写「更新当前配置档」，直接更新并轻量反馈，不追加确认框。
- 重命名：trim 后非空且唯一。
- 删除：当前启用配置档不可删除；非当前配置档删除前确认。
- 切换：无脏草稿时立即切换并保存；有脏草稿时提供「更新当前配置后切换」「放弃修改并切换」「取消」。
- 应用草稿：立即供 LLM 翻译使用，但不覆盖配置档，进入「自定义」状态；之后可另存或更新。
- Google/LLM 服务选择保持独立；切换配置档不得自动改成 LLM。
- 应用/保存前校验 Base URL、API key、model 均非空，URL 必须以 `http://` 或 `https://` 开头。
- API key 默认密码框，可临时显示/隐藏；切换配置档时仍默认掩码。
- 持久化失败必须回滚内存状态并给 Notice，不得静默假成功。

## 4. 设置页信息架构

LLM 服务选中时显示：

```text
LLM 配置档 [下拉：当前/自定义] [新建] [重命名] [删除]
API key [password] [眼睛图标]
Base URL
Model
翻译提示词
[Test] [应用当前修改] [保存为新配置档 / 更新当前配置档]
测试结果（非持久化）
```

字段输入只修改本地草稿，不得每个字符都 `saveData()`。目标语言、弹窗字号等非 LLM 连接设置可继续即时保存。

## 5. 非目标

- 不增加流式输出、模型列表发现、云端同步、配置导入导出、keychain、Google 配置档。
- 不改变目标语言语义、翻译历史/缓存、最大选区 5000 字符、Google/LLM 超时。
- 不在实现卡中 push GitHub；push 保留为用户 Gate。

## 6. 验收基线与防回归

- 当前基线：3 个测试文件、19 tests、0 skipped；`npm run test`、`npm run typecheck`、`npm run build`、`git diff --check` 全绿。
- 新代码必须增加纯逻辑/状态模型测试，不得删除、skip、弱化现有测试，不得 mock 被测核心函数来制造假绿。
- 必测：边界内几何定位、上下空间选择、窄区域宽度、45% 高度、滚动后不重定位、复制 icon 定时恢复；迁移幂等、名称冲突、当前配置删除保护、dirty switch 三分支、自定义状态、校验、测试不持久化、持久化失败回滚。
- 集成后构建并部署 `main.js`/`styles.css`/`manifest.json` 到 vault，逐文件 `cmp`。
- 最终 GUI Gate 由用户逐项验收；Agent 只能做客观 GUI smoke，不得代替用户批准视觉效果。
